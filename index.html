RSH Script Engine v2.3 - RadiumOS Documentation

Written for RadiumOS by scp_2801. RSH (RadiumOS Shell Script) is a lightweight cooperative scripting language that runs directly on the bare-metal RadiumOS kernel. It has no heap allocation, no dynamic memory, and uses fixed-size static buffers throughout. Scripts are loaded from AVFS, parsed into a flat line array, and executed cooperatively by the kernel.

1. Basics and File Structure

RSH scripts are plain text files stored in AVFS. They are executed by calling script_execute_file(path) from C, or via the RSH shell command.

A script is read top-to-bottom. Blank lines and comment lines are skipped. Every non-blank, non-comment line is a command. Lines are trimmed of leading and trailing whitespace before execution.

The maximum file size is 32768 bytes (32 KB). The maximum number of lines per file is 1000. Each line may be at most 255 characters.

The file extension .rsh is automatically tried if the given path does not exist verbatim. So script_execute_file("myscript") will also try myscript.rsh.

Entrypoint Declaration

If your script defines functions and wants execution to start from a main function rather than top-to-bottom, put this at the top of the file:

^entrypoint

This causes the engine to collect all function definitions first, then call main automatically. Without this directive, all non-function lines execute immediately as they are encountered top to bottom.

Include

You can include another RSH file with:

^include filename
^include "other_script.rsh"

Includes may be nested up to 8 levels deep. The included file runs in the same script context (shares variables, maps, and functions).

2. Comments

Any line beginning with % or # is a comment and is completely ignored.

% This is a comment
# This is also a comment
echo Hello   % inline comments are NOT supported - only full-line comments work

The special token __~~%~~__ at the start of a line is also treated as a comment (used internally).

3. Variables

Variables are untyped. They hold byte strings. Numbers are stored as decimal strings and parsed on demand. There is no type system.

Variable names may contain letters, digits, and underscores. They are case-sensitive. There are at most 32 variables active at once per scope.

Setting Variables

set NAME value
set NAME "value with spaces"
let NAME value
export NAME value

set, let, and export are identical. Calling set NAME with no value sets it to an empty string.

Variable Expansion

Use $NAME or ${NAME} anywhere in a line to substitute its value. Expansion happens before the command is parsed.

set X 42
echo The value is $X
echo Also works: ${X}

Unsetting Variables

unset NAME

Default Value

Set a variable only if it is currently empty or undefined:

default NAME fallback_value

Swap and Copy

swap A B      % exchanges values of A and B
copy SRC DST  % copies value of SRC into DST

Listing Variables

vars

Prints all currently defined variables and their values.

Hex Dump

dump VARNAME

Prints the raw bytes of a variable value as hex, useful for debugging binary content.

Special Variables Set by the Engine

  • ARG_COUNT - number of arguments passed to the current function
  • 1, 2, 3, ... - positional arguments inside a function
  • TICKS - set by the ticks command
  • INB - set by the inb command
  • INW - set by the inw command
  • INL - set by the inl command
  • ITER - current iteration index inside repeat
  • key and val - set automatically inside a with block

4. Output Commands

echo

echo Hello World
echo "Value is" $X

Prints all arguments separated by spaces, followed by a newline.

print

print Hello
print $X

Prints arguments concatenated with no separator and no trailing newline.

echoln

echoln VARNAME

Prints the value of the named variable followed by a newline. Takes a variable name, not a literal value.

printf

Formatted output. Supports format specifiers:

  • %s - string argument
  • %d - decimal integer argument
  • %x - hex integer argument (prints as 0xNNNN)
  • %% - literal percent sign
  • %n - newline
  • %t - typewriter effect: prints the string one character at a time with 100ms delay
set NAME scp_2801
printf "Hello %s you have %d items%n" $NAME 5
printf "Port value: %x%n" $PORTVAL

5. Math and Arithmetic

All math operates on 64-bit signed integers. Values are stored and read as decimal strings.

math

math RESULT_VAR expression
math X $A + $B
math Y $X * 3

Evaluates a simple arithmetic expression and stores the result. Supported operators: + - * /. Note: the expression parser is basic - it evaluates left to right after variable expansion and calls parse_int on the whole thing. For complex expressions use multiple math calls.

inc and dec

inc VARNAME         % adds 1
inc VARNAME 5       % adds 5
dec VARNAME         % subtracts 1
dec VARNAME 3       % subtracts 3

mod, div, pow

mod A B RESULT      % RESULT = A mod B
div A B RESULT      % RESULT = A / B (integer division)
pow BASE EXP RESULT % RESULT = BASE ^ EXP

sqrt, abs, min, max, clamp, sign

sqrt N RESULT           % integer square root
abs N RESULT            % absolute value
min A B RESULT          % smaller of A and B
max A B RESULT          % larger of A and B
clamp N LO HI RESULT    % clamps N to [LO, HI]
sign N RESULT           % -1, 0, or 1

rand

rand MIN MAX RESULT     % random integer in [MIN, MAX]

hex, dec2

hex N RESULT    % converts decimal N to hex string stored in RESULT (e.g. 0x1F)
dec2 N RESULT   % parses N (which may be hex) and stores decimal value

6. Bitwise Operations

band A B RESULT     % bitwise AND
bor  A B RESULT     % bitwise OR
bxor A B RESULT     % bitwise XOR
bnot A RESULT       % bitwise NOT (32-bit)
shl  A N RESULT     % shift A left by N bits
shr  A N RESULT     % shift A right by N bits
bit.set  A N RESULT % set bit N in A
bit.clr  A N RESULT % clear bit N in A
bit.test A N RESULT % result is 1 if bit N of A is set, else 0

7. String Operations

strlen

strlen VARNAME RESULT   % stores length of VARNAME's value in RESULT

substr

substr VARNAME START LEN RESULT
% extracts LEN characters starting at offset START from VARNAME's value

strcat

strcat DEST SRC1 SRC2 ...
% appends SRC values onto the end of DEST (modifies DEST in place)

strrep and strrep.all

strrep     VARNAME OLD NEW RESULT  % replace first occurrence of OLD with NEW
strrep.all VARNAME OLD NEW RESULT  % replace all occurrences

strupper, strlower

strupper VARNAME RESULT   % uppercase copy
strlower VARNAME RESULT   % lowercase copy

strfind

strfind VARNAME NEEDLE RESULT
% stores index of first occurrence of NEEDLE in VARNAME, or -1 if not found

strsplit

strsplit VARNAME SEPARATOR INDEX RESULT
% splits VARNAME's value by SEPARATOR and stores the token at INDEX
% INDEX is zero-based

strcount

strcount VARNAME NEEDLE RESULT
% counts how many times NEEDLE appears in VARNAME's value

strtrim

strtrim VARNAME RESULT
% stores a whitespace-trimmed copy of VARNAME's value in RESULT

strpad and strpad.r

strpad   VARNAME WIDTH PADCHAR RESULT  % left-pad to WIDTH using PADCHAR
strpad.r VARNAME WIDTH PADCHAR RESULT  % right-pad to WIDTH using PADCHAR

strhex

strhex VARNAME RESULT
% encodes each byte of VARNAME's value as two hex digits in RESULT

strrev

strrev VARNAME RESULT   % reverses the string

strjoin

strjoin SEPARATOR ARG1 ARG2 ... RESULT
% joins all ARG values with SEPARATOR and stores in RESULT
% RESULT is always the last argument

strstarts, strends

strstarts VARNAME PREFIX RESULT  % RESULT=1 if VARNAME starts with PREFIX
strends   VARNAME SUFFIX RESULT  % RESULT=1 if VARNAME ends with SUFFIX

strsub.r

strsub.r VARNAME N RESULT  % last N characters of VARNAME's value

8. Control Flow

if / elif / else / endif

if CONDITION
  ... body ...
elif OTHER_CONDITION
  ... body ...
else
  ... body ...
endif

Conditions support:

  • Comparison operators: == != < > <= >=
  • Logical operators: && ||
  • Negation: !CONDITION
  • Keyword checks: defined VARNAME, empty VARNAME, exists FILENAME, has MAPNAME KEY
  • Bare values: true false 1 0 yes no
  • Any non-empty non-zero string is truthy

Inline if (single-line)

if CONDITION do COMMAND
if CONDITION do COMMAND else OTHER_COMMAND
echo hello if $X == 5

A command followed by if CONDITION runs the command only if the condition is true. The do form is also supported. These are single-line only and cannot contain block bodies.

break, continue, return, exit

break       % exits current loop
continue    % skips to next loop iteration
return      % exits current function
exit N      % exits script with code N

assert

assert CONDITION
assert CONDITION "message if fails"

Prints an error and returns -1 if the condition is false.

9. Loops

while

while CONDITION
  ... body ...
endwhile

The maximum number of iterations is 100,000,000 as a safety limit. Use break to exit early.

for (range)

for VAR in START..END
  ... body ...
endfor

for VAR in START..END..STEP
  ... body ...
endfor

Iterates VAR from START to END (inclusive) with optional STEP. STEP may be negative for counting down.

for (token list)

for VAR in token1 token2 token3
  ... body ...
endfor

Iterates VAR over each whitespace-separated token in the list.

repeat

repeat N COMMAND

Runs COMMAND N times. The variable ITER holds the current zero-based iteration index.

10. Switch / Case

switch $VARIABLE
case value1
  ... body ...
endcase
case value2
  ... body ...
endcase
default
  ... body ...
endcase
endswitch

Compares the variable value against each case. Only the first matching case runs. The default block runs if no case matched. Variable expansion happens in both the switch value and the case values.

11. Functions

Functions are defined anywhere in the file. They do not execute at definition time. There is a maximum of 64 functions defined simultaneously. Each function body may have at most 128 lines. The call stack is at most 16 frames deep.

Defining a Function

function myfunction
  echo Running myfunction
  echo First arg is $1
  echo Second arg is $2
  echo Arg count is $ARG_COUNT
endfunction

def is an alias for function. Use enddef or endfunction to close.

One-time Functions

ont function setup
  echo This only runs once ever
endfunction

A one-time (or alt) function can only be called once. Calling it again produces an error.

Recursive Functions

By default, recursion is not allowed - the engine detects if a function is already on the call stack and refuses to re-enter it. To allow recursion, put ^allowedRecursive as the last line of the function body:

function countdown
  echo $1
  if $1 > 0 do call countdown $1 - 1
  ^allowedRecursive
endfunction

Calling Functions

call functionname arg1 arg2 arg3
functionname arg1 arg2 arg3

Both forms work. Arguments are accessible inside the function as $1, $2, etc. $ARG_COUNT holds the number of arguments passed.

Variable Scoping

When a function is called, all current variables are saved and restored when the function returns. Inside a function, you start with a clean variable table (only ARG_COUNT and $1..$N are defined). This means functions are fully scoped - they cannot accidentally modify caller variables.

Function Management Commands

func.list       % print all defined functions with pool slot info
func.drop NAME  % undefine a function and free its pool slot
pool.info       % show how many function body pool slots are used

once

once TAG COMMAND

Runs COMMAND the first time this tag is encountered, then never again even if called again. Tags persist for the lifetime of the script engine session.

12. Maps

Maps are key-value stores. Up to 16 maps may exist at once, each holding up to 32 entries. Keys are up to 32 bytes, values up to 128 bytes.

Declaring a Map in Script

const MAP mymap
  key1: value1
  key2: value2
  key3: 42
endMAP

editable MAP myeditable
  setting1: off
  setting2: 100
endMAP

const MAP declares a read-only map. editable MAP allows modification at runtime. Between editable MAP name and endMAP you may also use bare key value syntax (without the colon).

Map Commands

map.new NAME [editable]   % create a new empty map
map.set NAME KEY VALUE    % set a key in the map
map.get NAME KEY RESULT   % read a value from the map into RESULT
map.del NAME KEY          % delete an entry
map.has NAME KEY RESULT   % RESULT=1 if key exists
map.clear NAME            % delete all entries
map.count NAME RESULT     % number of entries
map.key NAME INDEX RESULT % get the Nth key (zero-based)
map.val NAME INDEX RESULT % get the Nth value
map.keys NAME RESULT      % space-separated list of all keys
map.vals NAME RESULT      % space-separated list of all values
map.merge SRC DST         % merge all entries from SRC into DST
map.copy SRC DST          % create DST as a full copy of SRC
map.drop NAME             % delete the entire map
map.dump NAME             % print all entries to terminal
map.sum NAME RESULT       % sum all numeric values
map.max NAME RESULT [KEYRESULT]  % maximum numeric value (and its key)
map.min NAME RESULT [KEYRESULT]  % minimum numeric value (and its key)
map.invert SRC DST        % create DST where keys and values are swapped
map.list                  % list all maps

Map Lookup via Variable Expansion

set K mykey
echo $mymap[$K]       % expands to the value at key mykey in mymap
echo $mymap[mykey]    % same thing with a literal key
echo $mymap['mykey']  % quoted literal key also works

with Block

with MAPNAME do
  echo Key is $key Value is $val
endwith

Iterates over every entry in the map. Inside the block, $key and $val hold the current entry's key and value.

13. File / AVFS Commands

fexists FILENAME RESULT   % RESULT=1 if file exists in AVFS
fsize   FILENAME RESULT   % RESULT = file size in bytes, or -1
fread   FILENAME RESULT   % reads file content into RESULT (up to 4096 bytes)
fwrite  FILENAME VARNAME  % writes VARNAME's value to file (overwrites)
fappend FILENAME VARNAME  % appends VARNAME's value to file
fdelete FILENAME          % removes file from AVFS
fline   FILENAME N RESULT % reads line N (zero-based) into RESULT
flinecount FILENAME RESULT% counts newlines in the file
fgrep   FILENAME NEEDLE RESULT % reads the first line containing NEEDLE

All file paths are passed to AVFS as null-terminated strings. The file read scratch buffer is 4096 bytes. Content longer than that is silently truncated when read into a variable.

14. Port I/O Commands

Direct hardware port access. These call outb/inb directly in the kernel.

outb PORT VALUE          % write 8-bit VALUE to I/O port PORT
inb  PORT [RESULT]       % read 8-bit value from PORT, store in RESULT (default INB)
outw PORT VALUE          % write 16-bit value to port
inw  PORT [RESULT]       % read 16-bit value, store in RESULT (default INW)
outl PORT VALUE          % write 32-bit value to port
inl  PORT [RESULT]       % read 32-bit value, store in RESULT (default INL)

io.wait PORT MASK EXPECTED_VAL [TIMEOUT_MS [OUT_VAR]]
% spins reading PORT until (value AND MASK) == EXPECTED_VAL
% or until TIMEOUT_MS milliseconds pass
% OUT_VAR (default IO_WAIT_OK) is set to 1 on success, 0 on timeout

You can also call outb inline using function-call syntax anywhere in a line:

outb(0x60, 0xFF)
set VAL inb(0x64)

15. VGA Text Commands

These write directly to the VGA text-mode framebuffer at 0xB8000. The screen is 80 columns by 25 rows. The attribute byte encodes foreground color in bits 0-3 and background color in bits 4-7.

cls                             % clear the terminal
color FG [BG]                   % set terminal color (0-15)
vgaput ROW COL CHAR ATTR        % write a single character at screen position
vgastr ROW COL STRING ATTR      % write a string starting at screen position
vgabar CURRENT MAX WIDTH        % draw a text progress bar [###...]
vgaclear ROW ATTR               % fill entire row with spaces using ATTR
vgafill ROW COL LEN CHAR ATTR   % fill LEN cells with CHAR using ATTR

Color values (0-15):

  • 0=Black, 1=Blue, 2=Green, 3=Cyan, 4=Red, 5=Magenta, 6=Brown, 7=Light Grey
  • 8=Dark Grey, 9=Light Blue, 10=Light Green, 11=Light Cyan, 12=Light Red, 13=Light Magenta, 14=Yellow, 15=White

16. Timing Commands

pause MS        % sleep for MS milliseconds
ticks [RESULT]  % store current PIT tick count in RESULT (default TICKS)
elapsed START_VAR RESULT  % RESULT = current_ticks - START_VAR

Ticks come from the PIT timer. At the default RadiumOS PIT frequency of 100 Hz, one tick equals 10ms. Use ticks and elapsed together to measure time:

ticks START
% ... do work ...
elapsed START DURATION
echo Elapsed ticks: $DURATION

20. Example: Keyboard Poller

The following script demonstrates a practical keyboard polling loop. It reads raw PS/2 scancodes directly from port 0x60 and translates the most common ones to their corresponding key names. It also shows how to use state variables, conditional logic, port I/O, and a clean exit condition - all without a main function (the script runs top to bottom).

Port 0x64 is the PS/2 status register. Bit 0 of its value indicates whether the output buffer is full (i.e. a scancode is waiting to be read). Port 0x60 is the PS/2 data port where the actual scancode byte is available.

Scancodes below 0x80 are key-press events. Scancodes at 0x80 and above are key-release events (the make code plus 0x80). Scancode 0x01 is the Escape key, which this script uses to terminate the polling loop.

% =============================================================
% RSH Keyboard Poller Example - RadiumOS / scp_2801
% Polls PS/2 port 0x60 and prints key names to the terminal.
% Press Escape to exit.
% No main function - runs top to bottom.
% =============================================================

% Set up constants for the PS/2 ports
set PS2_STATUS 0x64
set PS2_DATA   0x60
set SC_ESCAPE  0x01

% Display a header
cls
color 11
echo ==========================================
echo  RadiumOS RSH Keyboard Poller
echo  Press any keys. ESC to quit.
echo ==========================================
color 7
echo

% Track shift key state separately
% Shift make codes: 0x2A (left) and 0x36 (right)
% Shift break codes: 0xAA (left release) and 0xB6 (right release)
set SHIFT_HELD 0
set RUNNING 1
set LAST_SC 0

% Main polling loop
while $RUNNING == 1

  % Read PS/2 status register to check if data is available
  % Bit 0 of port 0x64 = output buffer full flag
  inb $PS2_STATUS STATUS_BYTE

  % Check if bit 0 is set (data ready)
  band $STATUS_BYTE 1 DATA_READY

  if $DATA_READY == 1

    % Read the scancode from port 0x60
    inb $PS2_DATA SCANCODE

    % Avoid processing the same scancode twice in a row
    % (some BIOS loops can repeat reads)
    if $SCANCODE == $LAST_SC
      pause 1
      continue
    endif
    set LAST_SC $SCANCODE

    % Check if this is a key release (scancode >= 0x80)
    % Key release = make code + 0x80
    if $SCANCODE >= 128

      % Calculate the make code by subtracting 128
      math MAKE_CODE $SCANCODE - 128

      % Handle shift release
      if $MAKE_CODE == 42
        set SHIFT_HELD 0
      endif
      if $MAKE_CODE == 54
        set SHIFT_HELD 0
      endif

      % Skip printing for release events
      continue

    endif

    % From here on, SCANCODE is a make (press) event

    % Handle Escape key - exit the loop
    if $SCANCODE == $SC_ESCAPE
      color 12
      echo ESC pressed - exiting keyboard poller.
      color 7
      set RUNNING 0
      continue
    endif

    % Handle left and right shift press
    if $SCANCODE == 42
      set SHIFT_HELD 1
      echo [SHIFT LEFT held]
      continue
    endif
    if $SCANCODE == 54
      set SHIFT_HELD 1
      echo [SHIFT RIGHT held]
      continue
    endif

    % Handle Caps Lock (scancode 0x3A = 58)
    if $SCANCODE == 58
      echo [CAPS LOCK toggled]
      continue
    endif

    % Translate common scancodes to key names
    % We use a map for this to keep the logic clean
    map.new KEYMAP

    map.set KEYMAP 2  1
    map.set KEYMAP 3  2
    map.set KEYMAP 4  3
    map.set KEYMAP 5  4
    map.set KEYMAP 6  5
    map.set KEYMAP 7  6
    map.set KEYMAP 8  7
    map.set KEYMAP 9  8
    map.set KEYMAP 10 9
    map.set KEYMAP 11 0
    map.set KEYMAP 16 q
    map.set KEYMAP 17 w
    map.set KEYMAP 18 e
    map.set KEYMAP 19 r
    map.set KEYMAP 20 t
    map.set KEYMAP 21 y
    map.set KEYMAP 22 u
    map.set KEYMAP 23 i
    map.set KEYMAP 24 o
    map.set KEYMAP 25 p
    map.set KEYMAP 30 a
    map.set KEYMAP 31 s
    map.set KEYMAP 32 d
    map.set KEYMAP 33 f
    map.set KEYMAP 34 g
    map.set KEYMAP 35 h
    map.set KEYMAP 36 j
    map.set KEYMAP 37 k
    map.set KEYMAP 38 l
    map.set KEYMAP 44 z
    map.set KEYMAP 45 x
    map.set KEYMAP 46 c
    map.set KEYMAP 47 v
    map.set KEYMAP 48 b
    map.set KEYMAP 49 n
    map.set KEYMAP 50 m
    map.set KEYMAP 28 ENTER
    map.set KEYMAP 14 BACKSPACE
    map.set KEYMAP 57 SPACE
    map.set KEYMAP 15 TAB
    map.set KEYMAP 72 UP
    map.set KEYMAP 80 DOWN
    map.set KEYMAP 75 LEFT
    map.set KEYMAP 77 RIGHT
    map.set KEYMAP 71 HOME
    map.set KEYMAP 79 END
    map.set KEYMAP 73 PAGE_UP
    map.set KEYMAP 81 PAGE_DOWN
    map.set KEYMAP 59 F1
    map.set KEYMAP 60 F2
    map.set KEYMAP 61 F3
    map.set KEYMAP 62 F4
    map.set KEYMAP 63 F5
    map.set KEYMAP 64 F6
    map.set KEYMAP 65 F7
    map.set KEYMAP 66 F8
    map.set KEYMAP 67 F9
    map.set KEYMAP 68 F10

    % Look up the key name
    map.has KEYMAP $SCANCODE KEY_KNOWN
    if $KEY_KNOWN == 1
      map.get KEYMAP $SCANCODE KEY_NAME

      % Apply shift for alphabetic keys
      if $SHIFT_HELD == 1
        strupper KEY_NAME KEY_NAME
      endif

      color 10
      printf "Key pressed: %s (scancode 0x%x)%n" $KEY_NAME $SCANCODE
      color 7

    else
      % Unknown scancode - print the raw hex value
      hex $SCANCODE SC_HEX
      color 14
      printf "Unknown scancode: %s%n" $SC_HEX
      color 7
    endif

    % Clean up the map each iteration so it doesn't fill up
    % (map entries persist until deleted)
    map.drop KEYMAP

  endif

  % Small delay to avoid hammering the port too fast
  pause 5

endwhile

% Done
color 11
echo Keyboard poller stopped.
color 7

How the Example Works

Port polling: Every iteration of the while loop reads port 0x64 (PS/2 status). The band command isolates bit 0. If it is 1, a scancode is ready to be read from port 0x60 via inb.

Key release filtering: PS/2 sends a break code (make code OR 0x80) when a key is released. Since 0x80 decimal is 128, any scancode at or above 128 is a release event. The script subtracts 128 to recover the original make code and checks if it was a shift key, then skips printing and uses continue to go to the next loop iteration.

Shift tracking: The variable SHIFT_HELD is set to 1 when a shift make code arrives and set back to 0 on the matching break code. This is used later to call strupper on the key name for letter keys.

Map-based lookup: Rather than a massive chain of if statements, the script loads all scancode-to-name mappings into a map and uses map.has and map.get to look up the name. The map is dropped and recreated each iteration because RSH maps have a maximum of 32 entries and we define more than that total here. In a real script you would define this map once before the loop if the entry count fits within the limit.

Hex fallback: For unrecognized scancodes, the hex command converts the decimal scancode to a hex string (like 0x4E) so the output is readable in PS/2 documentation format.

Exit condition: Scancode 0x01 is Escape. When detected, RUNNING is set to 0 and the while loop condition $RUNNING == 1 becomes false, terminating cleanly on the next iteration check.
