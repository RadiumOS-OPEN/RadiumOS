# save state version 1.0 


1.) Generate json code of files use `#include "../avfs/avfs.h"`


2.) Generate string of numbers based on json code (for testing purposes use 3 integer string of numbers) `calculate by ceasar cypher`

3.) Load string of numbers as a key (think of a usb drive)

4.) `s` key opens up savestate menu
    `1` Generates savestate key based on files
    `2` Loads savestate key 
    `ESC` Exits page `use ``return;`` `
